## 推导要点（v2）

假设同 v1：矩阵元 N(0, 0.02²)、零偏置、LN 增益 1、无 dropout；小初始化下注意力近似为对 K_i = mem+i 个 key 的均匀因果平均再乘 W_V W_O；输入 token iid（两两相关 ρ₀=0）。

逐子层追踪两个量：每 token 能量 E 与 token 两两平均内积 P=ρE。

- 前向，注意力：m = a(c₁ + ρ(1−c₁))，p = a(c₂ + ρ(1−c₂))，a = d²σ⁴
- 前向，FFN：m = b，p = 2b·k₁(ρ)，b = f d σ⁴/2，k₁ 为一阶 arc-cosine 核。即使 ρ=0，ReLU 的均值也使 FFN 输出有 1/π 的能量是 token 公共分量。
- 反向：在分支 s 注入 iid 扰动（能量 1、两两内积 0），逐层传播 (n, q)。注意力只对当前段 token 求导（memory 截断梯度）；FFN 的两两项乘 k₀(ρ)（两个 ReLU 同时激活的概率）。
- Post-LN：每个 LN 除以流能量；整体保留 1−2/d。

机制：token 越来越相关后，注意力的前向增益 v（含公共分量）大于对 iid 扰动的 Jacobian 增益 g，于是 (1+g)/(1+v) < 1 逐层累积，**越靠前的层传输越弱**。这与 Xiong et al. (2020) / DeepNet 中 Post-LN 靠近输出的层梯度更大的方向一致。在 σ=0.02 下幅度很小。

极限：σ→0 时，post/pre 的 T_s → 1−2/d，none 的 T_s → 1，即退化为（常数倍的）原始 NSC。

## 结果

### 1. MC 验证（开发集分层抽取 12 个真实规格，n=64，2 seeds × 2 probes）

| 设置 | v1 RMS 相对误差 | v2 RMS | v1 最大 | v2 最大 | 末层 ρ 实测 / v2 |
|---|---:|---:|---:|---:|---:|
| post，mem=0 | 3.3% | **1.2%** | 9.9% | **5.4%** | 0.079 / 0.075 |
| post，mem=64 | 2.9% | **1.3%** | 10.3% | **4.8%** | 0.075 / 0.073 |
| pre，mem=0 | 3.3% | 2.6% | 6.1% | 6.1% | 0.065 / 0.061 |
| pre，mem=64 | 2.4% | 2.2% | 5.5% | 5.5% | 0.062 / 0.060 |
| none，mem=0 | 1.0% | 1.0% | 2.9% | 2.9% | 0.080 / 0.075 |
| none，mem=64 | 0.9% | 0.8% | 2.3% | 2.3% | 0.076 / 0.073 |

- token 相关性预测的平均绝对误差约 0.004。
- v2 主要修正了 post（archive 的布局）；pre/none 下 v1 本已准确，v2 与之相当。
- Post-LN 配置内 T 剖面与实测的相关性 v1 0.63 → v2 0.70。剖面本身仅约 2–15% 的起伏，与 MC 噪声同量级，所以这个相关不高。
- 已知残余偏差：**第一个子层**实测比预测高约 4/d（12 seeds 复核：d=64 为 +6%，d=256 为 +1.7%）。原因是参考模型把未归一化的 N(0,1) 输入送进第一个 LN，per-token 1/σ 的涨落使其增益约为 d/(d−3)；后续 LN 的输入已归一化。这是参考输入设定的产物，没有写入评分。

### 5. 补强 MC 验证（2026-11-03，冻结前，不读标签）

`strengthen.py`：archive 实际的 n=mem=192；10 seeds × 2 probes（seed 1000–1009，与 `validation.json` 不重叠）；开发集按宽度取深度分位 0/.2/.4/.5/.6/.8/1，共 28 个规格（包含原 12 个）；对配置做 2000 次 bootstrap。24 核并行 22 进程，用时 1647 s。结果在 `strengthen.json`、`strengthen_rows.json`、`strengthen_log.txt`。预测公式与 `residual_transport.py` 相同，没有改动。

| 布局 | RMS 相对误差（95% CI） | 去掉第 1 子层 | 最大 | 配置均值 T 的 RMS 误差 | MC 标准误中位 | 落在 ±2SE 内 | 配置内剖面相关（均值 / 中位） |
|---|---|---:|---:|---:|---:|---:|---|
| **post（主方法）** | **0.81%（0.64–0.96%）** | **0.45%** | 5.7% | 0.49% | 0.33% | 89% | **0.81 / 0.92** |
| pre（对照） | 2.80%（2.16–3.40%） | 2.79% | 5.9% | 2.84% | 0.41% | 10% | 0.995 / 0.999 |
| none（对照） | 0.24%（0.21–0.28%） | 0.24% | 1.0% | 0.10% | 0.20% | 90% | 0.995 / 0.999 |

- 末层 token 相关：post 实测 0.0703 / 预测 0.0711。
- **post**：去掉第 1 子层后误差 0.45%，与 MC 噪声（0.33%）同量级。原来 n=64、2 seeds 时剖面相关只有 0.70，主要是噪声造成的；降噪后中位达到 0.92，说明预测的"前层略弱"趋势是真实存在的，只是幅度很小（配置内 max/min 中位 1.057）。
- **第 1 子层的残余偏差**按宽度分别为 −4.9% / −2.5% / −1.5% / −1.0%（d=64/128/256/512），与第 1 节记录的 ≈3–4/d 输入设定偏差一致。
- **pre 的系统偏差**：同一宽度内所有子层都偏低约 3/d（d=64 为 −4.9%，d=512 为 −0.9%）。来源与上一条相同：pre 的残差流从头到尾保留未归一化的 N(0,1) 输入，末端 LN 的 per-token 1/σ 涨落把这个偏差带给了所有子层。这只影响尺度，不影响形状（剖面相关 0.999），而 pre 只是错配对照，不进入主方法。

## 结论（开发集，待 final 确认）

1. **推导成立。** 三种布局的传输因子都能只从规格预测，含强信号区间；v2 修正了 v1 在 Post-LN 宽深模型上的系统偏差。
2. **Post-LN 下近似抵消。** 残差放大被 LN 抵消，层权重近似均匀（σ=0.02 时为 0.84–1.0），只剩由 token 相关性引起的、后层略大的弱趋势。pre/none 才会产生显著的位置依赖（且方向与 l/L 相反）。
3. **对排序无影响。** 本方法与消融在所有排序和选择指标上相同。按 proposal 的说法，这是一个有支撑的负结果：在该面板的 Post-LN、小初始化条件下，NSC 的等权求和是残差结构推出的一阶正确聚合，不是一个需要修正的任意选择。
4. **NSC 相对"报告参数量"的优势**来自排除 embedding（d=64 时宽度内 ρ 为 0.98 vs 0.09）；投影参数量同样能做到。在这个面板上，NSC 的非线性谱项几乎没有带来额外信息。

## 局限

- 参考模型省略相对位置注意力、embedding（含 adaptive 缩放）、dropout、softmax 的非均匀性及其导数；输入 token iid 不代表真实文本（真实 ρ₀ > 0 会放大第 2 点中的趋势）。
- 传输因子描述的是初始化时的信号传播，不是训练动态（参见 `../residual_foundations/`）。
- MC 已补强到 28 个开发集规格、10 seeds、n=mem=192，并报告了标准误（第 5 节）；它仍然只是初始化时的随机网络，不是训练后的模型。
- 开发集只有 100 个架构、每个一条结果，没有训练种子记录；选择结果的方差只来自平局与随机选择。
