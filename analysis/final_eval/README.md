## 结论

1. **开发集的负结果在 final 上得到复现。** 本方法与原始 NSC 在所有选择指标上完全相同；排序指标只差 ρ +0.0007、τ_b +0.0012，来自 4950 对中的 5 对翻转，在尺寸匹配对上没有任何差异。
2. 推导（MC 验证中 post 的 RMS 误差为 0.8%）和排序结果一致指向同一个结论：在这批 Post-LN、σ=0.02 的面板上，残差传输给出的层权重近似均匀，NSC 的等权求和已经是一阶正确的聚合方式。
3. **所有方法的匹配对 τ 都从 0.62 降到约 0.33。** 这是面板本身的现象（final 的同宽度、近同参数量对更难区分；d=512 的宽度内 ρ 只有 0.66），并非本方法特有。开发集上 0.62 的匹配 τ 不应被理解为稳定的属性。
4. 选择任务中，没有任何方法在所有预算下都占优：投影参数量在 20M/k1 略好，报告参数量在 30M 和 50M 更好，但在 10M 和 20M 明显更差。l/L 示例的排序指标略高（ρ 0.9690），但选择结果与 NSC 完全相同，而且它本身没有机制依据。
5. 打分成本：100 个架构冷启动 0.12 s（几乎全部花在 MP 积分上），热启动 5 ms；传输因子带来的额外开销可以忽略。

## 局限

与 `../meanfield_transport/README.md` 的局限一节相同。此外：final 只有 100 个架构，每个架构只有一条结果；test PPL 与开发集的 valid PPL 不是同一种指标；匹配对之间相互重叠，不是独立样本；没有对 ρ 的差异做显著性检验，因为只有 5 对翻转，差异显然在噪声范围内。
