# Post-LN 传输因子：规格预测、Monte Carlo 校验与排序影响（go/no-go）

日期：2026-10-18。目的：在实现 `student_score.py` 之前，判断 proposal 的"按残差传输因子加权 NSC"是否会实质改变开发集上的排序。**全程未读取任何标签文件**；只用 `architectures.json`、`splits.json`（开发集键）和 `resources.json`（参数量，用于匹配对与预算池）。

## 运行

```powershell
.\.venv\Scripts\python.exe analysis\postln_transport\transport.py
```

约 3.5 分钟（笔记本 CPU）。输出 `results.json`（汇总）和 `mc_rows.json`（每个配置、每种归一化的逐子层测量值）。

## 参考模型与定义

见 `transport.py` 文件头。要点：

- 子层顺序 attn_1, ffn_1, …, attn_L, ffn_L。三种布局：post `x←LN(x+F(x))`（archive 为 `pre_lnorm=false`）、pre `x←x+F(LN(x))` 加末端 LN、none `x←x+F(x)`。
- 所有矩阵元素 N(0, 0.02²)（NSC 约定），零偏置，LN 增益 1，无 dropout，无 memory、相对位置项、embedding 与词表头。
- 输入：n 个 iid、N(0,1) 的 token。
- 传输因子 `T_s = ||∂y/∂u_s||_F² / (n d)`，u_s 为子层 s 的分支输出。加权分数 `Σ_s T_s Ψ_s`，Ψ_s 为 starter 的 MP 容量按子层拆分；`T_s ≡ 1` 即原始 NSC（消融）。

### 规格预测（spec-only）

分支增益：FFN `v = f d σ⁴ / 2`；近均匀因果注意力 `v = d² σ⁴ · c_K`，`c_K` 为每个 query 可见 key 数倒数的均值（archive 用 tgt_len=192、mem_len=192）。iid 输入下前向方差增益等于 Jacobian 增益 g。

- none：`T_s = Π_{t>s}(1+v_t)`，前层权重更大。
- pre：`T_s ∝ Π_{t>s}(1 + v_t/var_t)`，var_t 为残差流方差的累积。前层权重更大，但幅度被 var_t 压低。
- post：自身 LN 除以 `1+v_s`，之后每个子层乘 `(1+g_t)` 又被其 LN 除以 `(1+v_t)`；g=v 时完全抵消，得 `T_s ≈ (1-2/d)/(1+v_s)`。**与位置无关，只依赖本子层宽度。**

## 结果

### 1. 预测 vs Monte Carlo（开发集中按宽度×深度分层抽取 12 个真实规格，n=64，2 seeds × 2 probes）

| 布局 | 平均相对误差 | 最大绝对相对误差 | 配置内 max/min T（中位） | 位置秩相关（均值） |
|---|---:|---:|---:|---:|
| post | +1.4% | 9.9% | 1.064 | −0.06 |
| pre | −0.8% | 6.1% | 1.118 | −0.96 |
| none | −0.3% | 2.9% | 1.119 | −0.94 |

- 无归一化与 Pre-LN：传输随位置单调递减（前层权重大），与 l/L 示例方向**相反**；预测准确。
- Post-LN：基本与位置无关，proposal 中"残差放大与 LN 近似抵消"的初步判断成立。
- **抵消并不精确的原因（已诊断）**：误差集中在 d=512、L≥11 的模型（预测高估 4–10%）。FFN 增益测量/预测 ≈ 1.00，但注意力的前向增益在深层达到预测值的 2–5 倍：因果平均使 token 逐层相关，iid 假设失效，前向增益 v 超过 Jacobian 增益 g，于是 `(1+g)/(1+v) < 1` 逐层累积。d≤256 时误差在 3% 以内。这是规格预测的一个明确局限，可作为报告中的机制性发现。

### 2. 玩具重排对（d=128，FFN [256,512] vs [512,256]）

post 的两种顺序分数完全相等（119.613184）；pre 和 none 有微小差异（前层较宽者略高）。即：在 archive 的 Post-LN 布局下，推导出的权重**不打破**原始 NSC 的重排平局。

### 3. 开发集上的排序影响（对照原始 NSC，不看 PPL）

| 加权 | 与 NSC 的 τ_b | 翻转对 / 4950 | 匹配对翻转 / 180 | top-k 成员变化（8 个 cap×k 组合） |
|---|---:|---:|---:|---|
| post（规格，主方法） | 0.9992 | 2 | 0 | 全部 0 |
| pre（错配对照） | 0.9903 | 24 | 2 | 10M/k=1 变 1 个 |
| none | 0.9952 | 12 | 2 | 30M/k=3 变 1 个 |
| l/L 示例 | 0.9503 | 123 | 4 | 10M k=1/k=3 各变 1 个 |

Post-LN 规格权重范围 0.919–0.996，单个配置内 max/min 中位数 1.024、最大 1.084。

## 判断

**按 proposal 原样实现，Post-LN 加权分数在开发集上与原始 NSC 几乎不可区分**：只翻转 2/4950 对，不影响任何规模匹配对和任何预算内选择。最终的 ρ、τ、选择 regret 几乎必然与消融相同。这本身是一个可以支撑的负结果（"在 Post-LN 与小初始化下，残差结构推出的层权重近似均匀，因此 NSC 的等权求和在该面板上是合理的"），但预测性评估部分将没有可比较的差异。

即便换成更准确的测量权重（配置内 spread ≤ 14%），也远小于 l/L 示例的 spread，而后者也只翻转 4 个匹配对；因此修正 iid 假设预计不会改变上述结论（未在全部 100 个配置上实测）。

需要在 milestone 前决定的选项：

1. **保留主线，定位为负结果/机制研究**：报告三种布局的推导与 MC 校验、Post-LN 近似抵消及其因 token 相关性而失效的条件，并用 pre/none 作为"若架构不同则权重会显著偏离"的对照。预测评估照常跑，诚实报告无差异。
2. **换一个在该面板上有区分度的机制**：例如 `analysis/residual_foundations` 提出的参数切线方向/有效秩，或 NSC 相对投影参数量（Spearman 0.9997）真正多出的信息。
3. 两者结合：1 作为主体，2 中选一个低成本的补充分析。

## 局限

- 参考模型省略相对位置注意力、memory、embedding（含 adaptive embedding 的缩放）和 dropout；LN 增益设为常数 1（Transformer-XL 某些实现以 N(1, 0.02) 初始化）。
- `proj_init_std=0.01` 的作用对象未知，统一用 0.02。
- MC 仅 12 个规格、n=64、2 seeds；误差条未报告。规格预测中的 `1-2/d` 因子为单次 LN 投影的近似，未单独验证。
