日期：2026-11-03，分支 `V1`。所有分析只读开发集标签。**final 已在 v2 中用过一次**，所以 V1 的任何 final 评估都只能作为"开发集上冻结、final 上只检验一次"的第二假设，并在报告中如实披露。

## 运行

## 1. 数据里 NSC 没用到的结构

200 个配置中，除了 NSC 用到的 `d_model`、逐层 `n_head`、逐层 `d_inner` 以外，还有两项会变化：**`d_embed`**（128/256/512）和 **`div_val`**（1/2/4，自适应嵌入的逐簇缩窄因子）。输入嵌入与输出 softmax 共享权重（`tie_weight=true`）；头簇的投影不共享（`tie_projs[0]=false`）。

嵌入形状模型已经与 `resources.json` 核对：`AdaEmb` = 各簇表 (tokens × d_embed/div^i) + 投影 (d_i × d_model) + 192·d_model，**200 个配置全部精确吻合**。

## 2. 残差分析（`explore.py`）

`log PPL ~ log 投影参数` 的 R² 为 0.915，NSC 为 0.918，两者几乎一样。

**在同一宽度内**，残差与嵌入大小高度相关：

| d_model | Spearman(残差, d_embed) | Spearman(残差, 嵌入参数) |
|---|---:|---:|
| 64 | −0.01 | +0.02 |
| 128 | −0.66 | −0.84 |
| 256 | −0.72 | −0.71 |
| 512 | −0.87 | −0.85 |

**天然对照实验**：同一宽度内，`d_embed` 与投影参数量几乎无关（Spearman 在 −0.12 到 0.01 之间），可以认为是独立分配的。

## 3. 机制：嵌入经过 d_model 投影时有秩瓶颈

嵌入表 E（tokens × d_i）先乘投影 P（d_i × d_model）才进入残差流，所以这条路径最多只有 min(d_i, d_model) 个方向能传过去。由此可以得到可证伪的剂量-饱和预测：**d_embed 超过 d_model 之后不应再有作用。**

各宽度、各 d_embed 的残差均值（log PPL，对 log NSC 回归后；负值代表更好）：

| d_model | d_embed=128 | 256 | 512 | 预测 |
|---|---:|---:|---:|---|
| 64 | +0.006 | −0.005 | +0.001 | 全部被截断 → 无作用 ✔ |
| 128 | +0.025 | −0.034 | −0.027 | 128→256 不应有作用（截断在 128），实测有作用 ✘；256→512 无作用 ✔ |
| 256 | +0.057 | −0.014 | −0.034 | 128→256 有作用 ✔；256→512 应饱和，实测仍有小幅作用 ~ |
| 512 | +0.091 | −0.013 | −0.058 | 一路有作用 ✔ |

注意 d=128 一行与简单截断不完全一致。d_embed 越大，div_val>1 时尾簇宽度 d_embed/div^i 也越大，也会越过瓶颈，下面的打分已经逐簇处理了这一点。这一点还需要进一步的机制检验。

## 4. 候选打分（零拟合参数）

`V1 = NSC + Σ_簇 ψ_MP(tokens_i, min(d_i, d_model), 0.02)`：共享的表只算一次，σ 采用 NSC 的约定。

| 打分 | ρ | 匹配 τ | 宽度内 ρ d64/128/256/512 |
|---|---:|---:|---|
| 原始 NSC | 0.9697 | 0.622 | 0.982 / 0.909 / 0.949 / 0.892 |
| NSC + 嵌入（不截断，消融 1） | 0.9242 | 0.444 | 0.332 / 0.766 / 0.969 / 0.927 |
| **V1：NSC + 截断嵌入** | **0.9829** | **0.656** | 0.969 / 0.940 / 0.983 / 0.910 |
| 投影参数量 | 0.9699 | 0.600 | 0.982 / 0.911 / 0.945 / 0.892 |
| 总参数量（嵌入按参数个数算） | 0.7279 | 0.133 | 0.089 / 0.482 / 0.657 / 0.904 |

- Bootstrap（重采样架构，5000 次）：Δρ = +0.014，95% CI [0.006, 0.025]，P(Δ≤0) = 0.0002。
- 去掉截断（消融 1）后结果明显变差，说明起作用的是瓶颈机制，而不只是"把嵌入加进去"。
- 选型 regret 只有 20M/k3 一处改善（0.57 → 0），其余与 NSC 相同。
- 诊断（拟合了 μ，**不作为方法**）：`log NSC + μ·log 截断嵌入` 在 μ=0.3 时 ρ 为 0.983、匹配 τ 为 0.744。说明聚合形式（加法还是乘法）仍有空间，但用了标签。

## 5. 结论：建议的研究方向

**"计算图中的串联瓶颈与共享权重：让 NSC 看见嵌入路径"。**

- **价值**：NSC 的盲区可以直接量化。仅一项结构特征（嵌入宽度）在宽度内就能解释大部分残差，而且这个效应在 NSC 和总参数量之间：一个完全忽略它，另一个把它放大了几百倍。
- **容易验证**：零拟合参数；数据里自带天然对照（d_embed 与层大小独立）；有可证伪的饱和预测；消融（去掉截断、去掉嵌入）可以清楚地分离机制。
- **成功概率**：开发集上已有显著提升（CI 不含 0）；剩下的工作主要是把截断的理论依据做扎实。

**风险与诚实披露**

1. final 已用过一次。V1 必须先在开发集上冻结（打 tag），final 只检验一次，并在报告中写明这是第二个假设。
2. 本轮已经在开发集上看过 4 个候选（不截断、截断、两种对数形式）。为了避免"分叉路径"的问题，只冻结零参数的截断版本，不再在开发集标签上继续试变体。
3. "截断"是近似：严格来说应当计算乘积 E·P 的谱容量，可以用 MP 乘积或 Monte Carlo 在**不读标签**的前提下检验它与截断近似的差距。
4. d=128 的 128→256 与简单截断预测不完全一致，需要逐簇分析或乘积谱来解释。
